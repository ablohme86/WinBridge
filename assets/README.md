# WinBridge icon

`winbridge.png` is the project icon, generated with the built-in image generation tool and preserved with its transparent background. The Qt resource system embeds it in the Manager, and the installer/package builder installs it for Linux desktop integration.

Generation prompt:

Use case: logo-brand. Asset: square desktop application icon for WinBridge Manager, readable at small sizes. A charming recognizable Tux Linux penguin meditating cross-legged with eyes gently closed, resting on a blue Windows four-pane logo drawn as a small flat platform. Bold clean silhouette, friendly polished 3D illustration with restrained detail, black and cream-white penguin, warm yellow beak and feet, blue platform and subtle violet rim lighting matching a dark navy and purple desktop app. Centered composition, fills 85 percent of square, no text, no letters, no extra symbols, no scenery. Genuinely transparent background with preserved alpha, no checkerboard painted into image. Output one high-quality 1024x1024 icon.
